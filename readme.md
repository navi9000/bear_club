# О проекте

Тестовое задание на позицию middle разработчика, найденное в интернете. Суть задачи заключается в создании страницы с заявками на вступление в клуб с возможностью принятия и отклонения заявок, а также просмотра списка заявок по категориям. Условием является написание проекта на чистом js без библиотек, фреймворков и т.п. Полный текст задачи можно найти по ссылке: https://github.com/ruport-digital/middle-frontend-assignment?tab=readme-ov-file

## Запуск проекта

npm run dev - запуск проекта для разработки
npm run build - сборка готового проекта для размещения в сети

## Основные характеристики проекта

- Проект на чистом js
- Основная логика реализована в виде паттерна MVC
- Добавлено кеширование запросов через встроенное cache api
- Для сохранения состояния заявок при обновлении страницы подключена indexeddb
- Для стилей не использовал модули, поэтому внешне классы стилей следуют паттерну BEM
- Для внутреннего наполнения классов стилей попробовал использовать одну идея с сайта css-tricks, заключающуюся в разбиении стилей на layout, typography, theming и effects. Эта часть получилась половинчатой. Кроме того, не уверен, что мне вообще нравится эта идея.
- Для сборки проекта использован rollup
